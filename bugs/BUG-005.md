# BUG-005: Ошибка компиляции — Unresolved reference 'OnboardingScreen' в AppNavGraph.kt

**Автор:** QA Tester
**Дата обнаружения:** 2026-03-14
**Связанная задача:** TASK-005
**Ветка/PR:** feature/TASK-005-navigation / PR #4
**Критичность:** Critical

---

## Описание

`AppNavGraph.kt` импортирует `OnboardingScreen` из пакета `com.example.localguide_planner.ui.onboarding`, однако этот класс отсутствует в ветке `feature/TASK-005-navigation`. Ветка была создана от `develop` (коммит `03d2380`), тогда как `OnboardingScreen` реализован в ветке `feature/TASK-004-onboarding` (коммит `e12c0c0`), которая ещё не смержена в `develop`.

В результате сборка (`./gradlew testDebugUnitTest`) завершается с ошибкой компиляции:

```
e: AppNavGraph.kt:12:42 Unresolved reference 'onboarding'.
e: AppNavGraph.kt:24:13 Unresolved reference 'OnboardingScreen'.
FAILURE: Build failed — compileDebugKotlin FAILED
```

Ни тесты, ни линтер не могут быть выполнены.

## Шаги воспроизведения

1. Переключиться на ветку `feature/TASK-005-navigation`
2. Запустить `./gradlew testDebugUnitTest`
3. Наблюдать ошибку компиляции в задаче `:app:compileDebugKotlin`

## Ожидаемый результат

Проект компилируется без ошибок. `OnboardingScreen` доступен в ветке, так как `feature/TASK-004-onboarding` смержена в `develop` перед созданием `feature/TASK-005-navigation` (или TASK-005 включает зависимость TASK-004 как базовую ветку).
