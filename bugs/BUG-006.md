# BUG-006: Hardcoded строки в AppNavGraph.kt и MainScreen.kt

**Автор:** QA Tester

**Ветка/PR:** feature/TASK-005-navigation / PR #4

## Описание

В четырёх местах кода используются hardcoded строки напрямую в Composable-функциях вместо ресурсов из `strings.xml`. Это нарушает стандарт кода из CLAUDE.md: "Строки только через `strings.xml`, нет hardcoded values".

Затронутые файлы:
- `AppNavGraph.kt` — 3 placeholder-текста
- `MainScreen.kt` — 1 placeholder-текст

## Шаги воспроизведения

1. Открыть `android core/app/src/main/java/com/example/localguide_planner/ui/navigation/AppNavGraph.kt`
2. Найти строки 43, 47, 54 — `Text(text = "Place detail placeholder")`, `Text(text = "Add place placeholder")`, `Text(text = "Edit place placeholder")`
3. Открыть `android core/app/src/main/java/com/example/localguide_planner/ui/main/MainScreen.kt`
4. Найти строку 76 — `Text(text = "Places list placeholder")`

## Ожидаемый результат

Все строки объявлены в `strings.xml` и используются через `stringResource(R.string.*)`:
```xml
<string name="placeholder_place_detail">Place detail placeholder</string>
<string name="placeholder_add_place">Add place placeholder</string>
<string name="placeholder_edit_place">Edit place placeholder</string>
<string name="placeholder_places_list">Places list placeholder</string>
```

## Фактический результат

Строки захардкожены непосредственно в Kotlin-коде:

```kotlin
// AppNavGraph.kt:43
Text(text = "Place detail placeholder")

// AppNavGraph.kt:47
Text(text = "Add place placeholder")

// AppNavGraph.kt:54
Text(text = "Edit place placeholder")

// MainScreen.kt:76
Text(text = "Places list placeholder")
```
