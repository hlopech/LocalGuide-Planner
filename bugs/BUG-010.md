# BUG-010: Кнопка «Повторить» в Error state вызывает навигацию назад вместо перезагрузки данных

**Автор:** QA Tester
**Дата обнаружения:** 2026-03-20
**Связанная задача:** TASK-012
**Ветка/PR:** feature/TASK-012-place-detail-ui / PR #15
**Критичность:** High

---

## Описание

В `PlaceDetailErrorContent` кнопка «Повторить» (`Button`) вызывает `onRetry`, которому при вызове передан `onNavigateBack`. Обе кнопки в Error state — «Повторить» и «Назад» — выполняют **идентичное действие**: возвращают пользователя на предыдущий экран. Перезагрузка данных через ViewModel не происходит.

## Шаги воспроизведения

1. Открыть экран деталей места с несуществующим ID (или смоделировать Error state через Preview).
2. Наблюдать Error state: иконка ошибки + текст + кнопки «Повторить» и «Назад».
3. Нажать кнопку «Повторить».

## Ожидаемый результат

Кнопка «Повторить» вызывает повторную загрузку данных через ViewModel (например, вызов `viewModel.loadPlace()` или аналогичного публичного метода). Пользователь остаётся на экране, данные загружаются заново.

## Фактический результат

Кнопка «Повторить» вызывает навигацию назад — то же самое, что кнопка «Назад». Повторная попытка загрузки данных невозможна.

## Среда воспроизведения

- **Android API:** minSdk 24 / targetSdk 36
- **Устройство/эмулятор:** любое
- **Версия приложения:** SPRINT-2

## Логи / Stack Trace

```
// PlaceDetailContent.kt, строка 158:

onNavigateBack = onNavigateBack,
```

## Скриншоты / Видео

Нет.

## Возможная причина

В `PlaceDetailContent` коллбэк `onRetry` не передаётся из `PlaceDetailScreen`. Функция `PlaceDetailScreen` не экспортирует метод повторной загрузки. `PlaceDetailViewModel` содержит приватный метод `loadPlace()` — необходимо добавить публичный метод `onRetryLoad()` в ViewModel и передать его цепочкой `PlaceDetailScreen → PlaceDetailContent → PlaceDetailErrorContent`.

## Для Developer (заполняется при фиксе)

**Корневая причина:** В `PlaceDetailContent` параметр `onRetry` передавался как `onNavigateBack`. Метод `loadPlace()` в ViewModel был приватным и недоступен из UI.

**Описание фикса:** Сделан `loadPlace()` публичным в `PlaceDetailViewModel`. Добавлен параметр `onRetryLoad: () -> Unit` в `PlaceDetailContent`. В `PlaceDetailScreen` передаётся `onRetryLoad = { viewModel.loadPlace() }`. В `PlaceDetailErrorContent` `onRetry` теперь получает `onRetryLoad` вместо `onNavigateBack`.

**Файлы изменены:**
- `android core/app/src/main/java/com/example/localguide_planner/ui/places/detail/PlaceDetailScreen.kt`
- `android core/app/src/main/java/com/example/localguide_planner/ui/places/detail/PlaceDetailViewModel.kt`
