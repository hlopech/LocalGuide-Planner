# BUG-011: Функции PlaceDetailContent и PlaceDetailSectionsColumn превышают лимит 50 строк

**Автор:** QA Tester

**Связанная задача:** TASK-012
**Ветка/PR:** feature/TASK-012-place-detail-ui / PR #15
**Критичность:** High

## Описание

Два composable в `PlaceDetailScreen.kt` нарушают стандарт проекта «функции не длиннее 50 строк» (CLAUDE.md) и явный критерий приёма TASK-012 («Функции не длиннее 50 строк»).

- `PlaceDetailContent` (строки 108–169): **62 строки**
- `PlaceDetailSectionsColumn` (строки 303–372): **70 строк**

## Шаги воспроизведения

1. Открыть файл `android core/app/src/main/java/com/example/localguide_planner/ui/places/detail/PlaceDetailScreen.kt`.
2. Посчитать строки функций `PlaceDetailContent` (строки 108–169) и `PlaceDetailSectionsColumn` (строки 303–372).

## Ожидаемый результат

Все функции содержат не более 50 строк. Длинные функции разбиты на вспомогательные приватные composable.

## Фактический результат

- `PlaceDetailContent`: 62 строки (превышение на 12 строк). Функция содержит полную настройку `Scaffold` с `LargeTopAppBar` (многострочный блок actions/navigationIcon/colors).
- `PlaceDetailSectionsColumn`: 70 строк (превышение на 20 строк). Функция содержит диалог, перечисление всех секций, кнопку избранного и кнопку удаления.
