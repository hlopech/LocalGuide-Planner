# BUG-012: Неиспользуемые строки place_detail_favorite_add и place_detail_favorite_remove в strings.xml

**Автор:** QA Tester
**Дата обнаружения:** 2026-03-20
**Связанная задача:** TASK-012
**Ветка/PR:** feature/TASK-012-place-detail-ui / PR #15
**Критичность:** Medium

---

## Описание

В `strings.xml` существуют две строки из предыдущей реализации, которые более не используются ни в каком файле проекта:

- `place_detail_favorite_add` = "Добавить в избранное"
- `place_detail_favorite_remove` = "Убрать из избранного"

Developer заменил их на новые ключи `place_detail_action_add_favorite` и `place_detail_action_remove_favorite`, но старые ключи не удалил. Android Lint фиксирует `UnusedResources` для обеих строк.

Дополнительно: `place_detail_action_remove_favorite` = "Убрать из избранного" полностью дублирует значение `place_detail_favorite_remove` = "Убрать из избранного" — семантическое дублирование ресурсов.

## Шаги воспроизведения

1. Открыть `android core/app/src/main/res/values/strings.xml`.
2. Найти строки `place_detail_favorite_add` (строка 32) и `place_detail_favorite_remove` (строка 33).
3. Поиском по проекту убедиться, что ни один файл `.kt` не содержит ссылки на `R.string.place_detail_favorite_add` или `R.string.place_detail_favorite_remove`.
4. Запустить `./gradlew :app:lintDebug` — в отчёте будут `UnusedResources` предупреждения.

## Ожидаемый результат

В `strings.xml` нет неиспользуемых строк. Строки `place_detail_favorite_add` и `place_detail_favorite_remove` либо используются в коде, либо удалены.

## Фактический результат

Строки `place_detail_favorite_add` и `place_detail_favorite_remove` присутствуют в `strings.xml` и не используются ни в одном файле Kotlin. Lint-отчёт (`lint-results-debug.txt`) содержит:
