# BUG-033: Использование устаревшего (deprecated) overload SearchBar

**Автор:** QA Tester
**Дата обнаружения:** 2026-03-21
**Связанная задача:** TASK-014
**Ветка/PR:** feature/TASK-014-search-and-filters / PR #16
**Критичность:** Medium

---

## Описание

В `PlacesListScreen.kt` (строка 256) используется устаревший overload Material3 `SearchBar`:

```kotlin
SearchBar(
    query = query,
    onQueryChange = onQueryChange,
    onSearch = { active = false },
    active = active,
    onActiveChange = { active = it },
    ...
)
```

При компиляции Kotlin выдаёт предупреждение:

```
w: 'fun SearchBar(query: String, onQueryChange: (String) -> Unit, onSearch: (String) -> Unit, active: Boolean, onActiveChange: (Boolean) -> Unit, ...): Unit' is deprecated. Use overload which takes inputField as a parameter.
```

Данный overload помечен `@Deprecated` в актуальной версии Material3. Это техническое нарушение стандарта кода проекта («KTLint без ошибок» подразумевает использование актуальных API).

## Шаги воспроизведения

1. Запустить сборку: `./gradlew :app:compileDebugKotlin`
2. Наблюдать предупреждение о deprecated API в выводе компилятора.

## Ожидаемый результат

Использование актуального overload `SearchBar` с параметром `inputField`, поддерживаемого текущей версией Material3.

## Фактический результат

Код компилируется с предупреждением `@Deprecated`. В будущих версиях Material3 данный overload может быть удалён.

## Среда воспроизведения

- **Android API:** API 24+
- **Compose BOM:** 2024.09.00
- **Версия приложения:** 1.0 (versionCode 1)

## Скриншоты / Видео

Не применимо.

## Возможная причина

Developer использовал старый API SearchBar, не учтя что в текущей версии Material3 (BOM 2024.09.00) данный overload уже помечен как deprecated.
