# BUG-035: Hardcoded строка "—" в ProfileHeroSection вместо R.string.*

**Автор:** QA Tester
**Дата обнаружения:** 2026-03-21
**Связанная задача:** TASK-015
**Ветка/PR:** feature/TASK-015-profile-screen / PR #17
**Критичность:** Medium

---

## Описание

В функции `ProfileHeroSection` файла `ProfileScreen.kt` на строке 121 используется hardcoded строка-прочерк `"—"` вместо ресурса `R.string.*`. Это нарушает стандарт кода проекта: «Строки только через `strings.xml`» (CLAUDE.md).

```kotlin
Text(
    text = userName.ifEmpty { "—" },   // строка 121 — hardcoded!
    style = MaterialTheme.typography.headlineMedium,
    color = Color.White,
)
```

В `strings.xml` уже существует подходящий ресурс `profile_stat_top_category_none` (`"—"`), который мог бы быть использован, либо необходимо добавить отдельный ресурс для данного случая (например, `profile_hero_name_empty`).

## Шаги воспроизведения

1. Открыть `ProfileScreen.kt`.
2. Найти функцию `ProfileHeroSection` (строки 102–127).
3. Строка 121: `text = userName.ifEmpty { "—" }`.

## Ожидаемый результат

Строка-заглушка должна быть задана через `stringResource(R.string.profile_hero_name_empty)` или аналогичный ресурс из `strings.xml`.

## Фактический результат

Строка `"—"` зашита прямо в Kotlin-код, не локализуема и не соответствует стандарту проекта.
