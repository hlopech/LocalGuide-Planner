**Связанная задача:** TASK-015

**Критичность:** Medium

## Описание

Функция `MainScreen` в файле `MainScreen.kt` занимает 76 строк (строки 48–123), нарушая правило CLAUDE.md: «Функции не длиннее 50 строк — рефакторить при превышении».

```kotlin
@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun MainScreen(                // строка 48
    onNavigateToDetail: (String) -> Unit = {},
    onNavigateToAdd: () -> Unit = {},
) {
    // ... 76 строк тела функции
}                              // строка 123
```

В рамках TASK-015 в функцию были добавлены: логика вычисления `currentTitle` (~9 строк), вторая вкладка в навигации и маршрут Profile в NavHost. Суммарно это привело к превышению допустимого размера функции.

## Шаги воспроизведения

1. Открыть `MainScreen.kt`.
2. Подсчитать строки функции `MainScreen` (48–123).
3. Результат: 76 строк (превышение на 26 строк).

## Ожидаемый результат

Функция `MainScreen` не превышает 50 строк. TopBar, BottomBar и NavHost должны быть вынесены в отдельные private Composable-функции.

## Фактический результат

Функция занимает 76 строк. Рекомендуется рефакторинг: выделить `MainTopBar`, `MainBottomBar` и/или `MainNavHost` в отдельные Composable.

## Среда воспроизведения

- **Файл:** `android core/app/src/main/java/com/example/localguide_planner/ui/main/MainScreen.kt`
- **Строки:** 48–123
