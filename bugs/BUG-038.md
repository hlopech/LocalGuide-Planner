# BUG-038: Карта всегда центрируется на Москве, игнорируя места с координатами

**Автор:** QA Tester
**Дата обнаружения:** 2026-03-21
**Связанная задача:** TASK-017
**Ветка/PR:** feature/TASK-017-map-osmdroid / PR #19
**Критичность:** High

---

## Описание

`OsmMapView` создаёт `MapView` через `remember { mutableStateOf(createMapView(context, places)) }`. На момент первой композиции `OsmMapView` значение `uiState.places` всегда равно `emptyList()` (начальное состояние `MapUiState` — `isLoading = true, places = emptyList()`). В результате `createMapView` вызывается с пустым списком, `firstWithCoords` всегда равен `null`, и карта всегда центрируется на Москве (55.7558, 37.6173).

После загрузки данных `AndroidView.update` вызывает `updateMapMarkers`, который корректно добавляет маркеры, но никогда не выполняет повторного центрирования. Таким образом, DoD-критерий "Карта центрируется на первом месте с координатами (или Москва при отсутствии)" никогда не выполняется для случая, когда места с координатами существуют.

## Шаги воспроизведения

1. Добавить в приложение хотя бы одно место с координатами (например, `latitude = 59.9343, longitude = 30.3351` — Санкт-Петербург).
2. Открыть вкладку «Карта».
3. Дождаться загрузки маркеров.

## Ожидаемый результат

Карта центрирована на первом месте из списка, имеющем ненулевые координаты. Маркер этого места виден в центре экрана при открытии вкладки.

## Фактический результат

Карта всегда центрирована на Москве (55.7558, 37.6173), даже если существуют места с координатами. Маркеры добавляются корректно, но пользователю нужно вручную прокрутить карту к ним.

## Возможная причина

`remember { mutableStateOf(createMapView(context, places)) }` вычисляется ровно один раз при первой композиции, когда `places = emptyList()`. Функция `createMapView` определяет центр карты только при создании `MapView`. Блок `update` в `AndroidView` (`updateMapMarkers`) не содержит логики повторного центрирования при получении данных.

**Возможное исправление:** перенести логику центрирования в блок `update` `AndroidView` (вызывать `controller.setCenter` при первом появлении мест с координатами — например, через `rememberSaveable` флаг `isCentered`), или передавать `places` в `remember` как ключ при наличии коодинат.
