# BUG-039: Hardcoded строка "osmdroid" в вызове getSharedPreferences

**Автор:** QA Tester
**Дата обнаружения:** 2026-03-21
**Связанная задача:** TASK-017
**Ветка/PR:** feature/TASK-017-map-osmdroid / PR #19
**Критичность:** Medium

---

## Описание

В функции `createMapView` (`MapScreen.kt`, строка 115) при инициализации конфигурации OSMDroid используется hardcoded строка `"osmdroid"` в качестве имени SharedPreferences:

```kotlin
context.getSharedPreferences("osmdroid", Context.MODE_PRIVATE)
```

Это нарушает стандарт проекта "Нет hardcoded строк" (CLAUDE.md) и DoD-критерий TASK-017 "Нет hardcoded строк". Строковый литерал должен быть объявлен как `private const val`.

## Шаги воспроизведения

1. Открыть файл `android core/app/src/main/java/com/example/localguide_planner/ui/map/MapScreen.kt`.
2. Найти строку 115.

## Ожидаемый результат

Имя SharedPreferences вынесено в именованную константу:
```kotlin
private const val OSMDROID_PREFS_NAME = "osmdroid"
// ...
context.getSharedPreferences(OSMDROID_PREFS_NAME, Context.MODE_PRIVATE)
```

## Фактический результат

```kotlin
context.getSharedPreferences("osmdroid", Context.MODE_PRIVATE)
```
Строка захардкожена непосредственно в вызове.

Не применимо.

## Возможная причина

Строка-ключ для SharedPreferences не была вынесена в константу при написании функции `createMapView`.
