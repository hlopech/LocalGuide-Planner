# BUG-040: Отсутствует @Preview для публичного Composable MapScreen

**Автор:** QA Tester
**Дата обнаружения:** 2026-03-21
**Связанная задача:** TASK-017
**Ветка/PR:** feature/TASK-017-map-osmdroid / PR #19
**Критичность:** Medium

---

## Описание

Публичная Composable-функция `MapScreen` в файле `MapScreen.kt` не имеет аннотации `@Preview`. Согласно стандарту проекта CLAUDE.md: "Каждый публичный Composable должен иметь `@Preview`". DoD-критерий TASK-017 также требует: "`@Preview` для `MapScreen` показывает заглушку (без реального MapView)".

В PR добавлены только `@Preview` для `internal fun MapContent` (`MapContentLoadingPreview`, `MapContentWithPlacesPreview`). Функция `MapScreen` — публичная и не имеет ни одного `@Preview`.

## Шаги воспроизведения

1. Открыть файл `android core/app/src/main/java/com/example/localguide_planner/ui/map/MapScreen.kt`.
2. Найти функцию `fun MapScreen(...)` (строки 41–52).
3. Убедиться в отсутствии `@Preview` аннотации над функцией.

## Ожидаемый результат

`MapScreen` имеет `@Preview` аннотацию, демонстрирующую заглушку (без реального `MapView`). Например:

```kotlin
@Preview(showBackground = true)
@Composable
private fun MapScreenPreview() {
    LocalGuidePlannerTheme {
        // preview stub без hiltViewModel
    }
}
```

Поскольку `MapScreen` использует `hiltViewModel()`, допустимо задокументировать невозможность прямого preview и использовать `MapContent` как целевую функцию для preview. Однако в этом случае CLAUDE.md и DoD требуют явного `@Preview` для публичного composable или явного исключения.

## Фактический результат

Публичная функция `MapScreen` не имеет `@Preview`. Доступные preview (`MapContentLoadingPreview`, `MapContentWithPlacesPreview`) покрывают `internal fun MapContent`, но не `fun MapScreen`.

## Возможная причина

`MapScreen` использует `hiltViewModel()`, что несовместимо с `@Preview` в стандартной конфигурации. Разработчик добавил `@Preview` только для `MapContent`. Требуется либо добавить `@Preview` для `MapScreen` с явной заглушкой ViewModel (через `PreviewParameterProvider` или аналог), либо зафиксировать отклонение от стандарта.
