# BUG-043: AddEditPlaceFormContent превышает лимит 50 строк (55 строк) после рефакторинга в TASK-018

**Автор:** QA Tester
**Дата обнаружения:** 2026-03-25
**Связанная задача:** TASK-018
**Ветка/PR:** bugfix/TASK-018-sprint4-bugfix / PR #20
**Критичность:** Low

---

## Описание

Критерий приёма TASK-018 требует: «`AddEditPlaceFormContent` разбита на private composable — ни одна функция не превышает 50 строк».

После рефакторинга в PR #20 функция `AddEditPlaceFormContent` в файле `AddEditPlaceScreen.kt` (строки 136–190) занимает **55 строк**, что превышает допустимый лимит на 5 строк.

```kotlin
@Composable
private fun AddEditPlaceFormContent(   // строка 136
    uiState: AddEditPlaceUiState,
    onNameChange: (String) -> Unit,
    onAddressChange: (String) -> Unit,
    onDescriptionChange: (String) -> Unit,
    onCategoryChange: (PlaceCategory) -> Unit,
    onSaveClicked: () -> Unit,
    modifier: Modifier = Modifier,
) {
    // ... тело функции
}                                       // строка 190
```

Хотя Developer правильно выделил `PlaceNameField`, `PlaceAddressField`, `PlaceDescriptionField`, `PlaceCategorySelector` — сама `AddEditPlaceFormContent` всё ещё превышает 50 строк из-за того, что `LazyColumn` с 5 `item { AnimatedFormField(...) }` блоками остался в теле функции.

## Шаги воспроизведения

1. Открыть файл `android core/app/src/main/java/com/example/localguide_planner/ui/places/addedit/AddEditPlaceScreen.kt` из ветки `bugfix/TASK-018-sprint4-bugfix`.
2. Найти функцию `AddEditPlaceFormContent` (строки 136–190).
3. Подсчитать строки: 190 - 136 + 1 = 55 строк.

## Ожидаемый результат

Функция `AddEditPlaceFormContent` не превышает 50 строк согласно стандарту кода проекта и критерию приёма TASK-018.

## Фактический результат

Функция занимает 55 строк. Превышение на 5 строк.

## Возможная причина

`LazyColumn` с 5 блоками `item { AnimatedFormField(...) }` остался в теле `AddEditPlaceFormContent`. Несмотря на вынесение полей в отдельные private composable, размер функции превышает лимит из-за количества `item`-блоков (каждый занимает 4 строки).
