## 1. О продукте

**LocalGuide Planner** — персональный Android-компаньон для исследования города.
Помогает пользователям сохранять интересные места, организовывать их в коллекции,
планировать прогулки, фиксировать посещения и отслеживать маршруты.

Это не просто карта с пинами — это структурированный дневник городского исследователя.

---

## 2. Цели продукта

- Сохранять интересные места и управлять ими
- Категоризировать и фильтровать места
- Группировать места в тематические коллекции
- Планировать городские вылазки
- Фиксировать посещения и впечатления
- Записывать пешие маршруты
- Просматривать посещённые/непосещённые места по районам
- Обнаруживать паттерны в исследовании города

## 5. Ключевые продуктовые решения

### 5.1 Offline-first
- Все данные хранятся локально в Room и DataStore
- Приложение полностью работает без интернета
- Архитектура должна быть готова к будущей онлайн-синхронизации (Repository abstraction)

### 5.2 Профиль пользователя (локальный)
- При первом запуске пользователь проходит онбординг: вводит имя и выбирает аватар
- Данные профиля хранятся в **DataStore Preferences**
- Регистрация/логин через сервер — в будущем; сейчас только локальный профиль
- Архитектура не должна исключать добавление Firebase Auth в будущем

### 5.3 Карты
- Решение по провайдеру (Google Maps / OpenStreetMap / Mapbox) — на усмотрение Tech Director
- Первый спринт не включает карты

## 6. Спринты

### Sprint 1 — Foundation (текущий)
**Цель:** рабочее приложение с базовой структурой, локальным профилем и управлением местами.

**Scope:**
- [ ] Онбординг / локальный профиль пользователя
- [ ] Базовая навигация (bottom navigation, граф экранов)
- [ ] Places: список мест
- [ ] Places: детали места
- [ ] Places: добавление/редактирование места

**Definition of Done Sprint 1:**
- Пользователь может создать локальный профиль при первом запуске
- Пользователь может просматривать список сохранённых мест
- Пользователь может открыть детали любого места
- Пользователь может добавить новое место и отредактировать существующее
- Всё работает без интернета
- Unit-тесты на ViewModel и UseCase написаны

### Sprint 2 — Core Features (планируется)
Collections, Search & Filters, Visits

### Sprint 3 — Extended Features (планируется)
Plans, Districts, Dashboard

### Sprint 4 — Advanced (планируется)
Walk Sessions (GPS), Analytics
